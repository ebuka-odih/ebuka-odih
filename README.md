### ⚡ How I work

- 🌍 **Build for the real world.** Patchy internet, many languages, cheap phones. Those are design inputs, not edge cases.
- 🤖 **Agents do the legwork, people make the call.** Every agent I ship proposes; a human confirms.
- ✅ **"Done" means proven.** If it isn't tested and checked, it isn't finished.
